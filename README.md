# Un cours de cuisine thaïlandaise

Page statique d'une page : l'annonce d'un cours de cuisine thaïlandaise
aux Ateliers & Saveurs du Vieux-Montréal, avec le menu de la soirée.

Reprend la mise en page d'une carte imprimée au format A5 : Cormorant
Garamond et Karla, papier crème, vert profond et laiton.

## Utilisation

Aucune dépendance, aucune étape de build. Ouvrir `index.html` dans un
navigateur, ou servir le dossier tel quel.
